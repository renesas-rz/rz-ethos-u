# meta-rz-ethos-u-examples

This OpenEmbedded/Yocto layer provides example Ethos-U applications
(MobileNet V2 Classifier and Model Executor) that can be run on the
Renesas RZ/G3E SMARC Evaluation platform, along with their required
dependencies (OpenCV and XDG shell protocol for Wayland).

This layer is dependent on the
[meta-rz-ethos-u layer](../meta-rz-ethos-u), which adds support for the
software and drivers needed to enable Ethos-U functionality.

Further information about how to use this meta-layer can be found in the
top-level [README.md](../README.md) of this repository.
