# Offline Compilation Environment

This directory contains the Python Virtual Environment requirements and
wrapper script needed for model compilation on a Host PC.

For information about how to set up the virtual environment and compile
AI models, please see
[RZ/G3E NPU (Ethos-U55) Support Documentation Page - Prepare Target AI Model section](https://renesas-rz.github.io/rz-ethos-u-docs/prepare-models/)
